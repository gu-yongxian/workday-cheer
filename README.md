# 上班鼓励器

每一秒，都算数。

在线使用：https://gu-yongxian.github.io/workday-cheer/

支持月薪、上下班、午休、单双休与自定义休息日，提供实时收入、下班倒计时、工作进度、咖啡小目标和桌面悬浮窗。工资和排班只保存在本机浏览器。

Mac：Safari 文件菜单 → 添加到程序坞（macOS Sonoma 14+）。Chrome / Edge 可通过浏览器菜单安装为应用，并在支持时开启置顶小窗。Safari 的独立小窗不置顶。

也可下载 downloads/workday-cheer-offline.zip，解压并打开 index.html。
